# Reconstructing User Sessions & Analyzing Conversion Funnel in Clickstream Data
Tools: Python · Pandas · Matplotlib · Jupyter Notebook
Dataset: ~75K events · E-commerce clickstream · Kaggle Source  
https://www.kaggle.com/datasets/waqi786/e-commerce-clickstream-and-transaction-dataset

# Business Problem
E-commerce platforms rely heavily on understanding user behavior to improve conversion rates and customer engagement.

However, in this dataset, the provided session information is unreliable, making it difficult to accurately track user journeys and identify meaningful behavioral patterns.

Without proper session tracking, businesses cannot:

Understand how users navigate the platform
Identify where users drop off before purchase
Measure engagement and retention effectively

Therefore, the key challenge is to reconstruct user sessions and analyze interaction patterns to uncover actionable insights for improving conversion and user experience.
